# Miglore OS — 首页线框设计 (Home)

> 设计语言：**App Store 的信息组织**（Hero → 横向 shelf → 卡片网格）+ **个人成长系统的数据感**（进度/连续天数/技能）+ **个人操作系统的掌控感**（今日任务/时间线）。
> 目标一句话：**打开首页，5 秒内知道「我在哪、学到哪、今天干什么、最近干了什么」。**
> 不做传统后台 Dashboard（无密排表格、无侧边统计面板堆砌）。

## 2. 分区说明

### 2.1 顶栏（吸顶）
- 左：`Miglore OS` 标志（文字 + 简单几何标）
- 中：模块快速导航（Home / Learning / Career / Projects / Tasks / Journal / Blog，当前态高亮）
- 右：⌕ 模块搜索（全局过滤，V1 可只做前端过滤）、暗色开关（预留）、头像菜单

### 2.2 HERO · 当前职业路线（全宽大卡，渐变底色）
- 左上角：今日日期 + 星期 + **连续学习天数徽标**（🔥 12 天）
- 主标题：职业目标（来自 `users.career_goal`）——"DevOps 工程师"
- 右侧：**当前路线进度环**（68%）+ 当前阶段名 + 进度条 + 主 CTA「继续学习 →」（跳到该路线进行中的第一个任务）
- 数据源：`/api/dashboard.hero`
- 设计语言：全页唯一的"重"元素，类似 App Store Today 大卡，但内容换成职业与学习

### 2.3 Continue Learning（shelf 1，横向滚动）
- 取 `status=in_progress` 且最近的 3-5 个学习任务
- 卡片：任务名 + 路线名 + 预估时长徽标 + 「继续」按钮
- 点击 → 打开任务详情/直接标记完成（实现阶段定）
- 空态：引导「添加第一个学习任务」

### 2.4 Learning Progress（shelf 2）
- 技能进度条组（`/api/dashboard.learning_progress`，取 5-6 个活跃技能）
- 每项：技能名 + 进度条（level/target_level）+ 分数徽标 `4/5`
- 右下角「技能清单 →」跳 /learning

### 2.5 Featured Projects（网格）
- 取 `featured=1` 的项目，2-3 列网格
- 卡片：项目名 + 技术栈标签 + 进度条 + 状态徽标
- 空态：引导「创建第一个项目」（Miglore OS 本身就是第一个）

### 2.6 Today's Tasks（左栏）
- `due_date=today 且 status!=done` 的任务，按优先级降序
- 行：勾选框（点击乐观完成）+ 标题 + 优先级徽标（高/中/低）
- 底部：「+ 添加任务」内联快速添加（回车即建，type 默认 daily）
- 全部完成 → 显示祝贺空态（"今天已清空 🎉"）

### 2.7 Recent Activity（右栏）
- 最近 5 条 `study_logs`（按 log_date 倒序）+ 任务完成/投递事件
- 行：相对日期 + 内容摘要 + 时长徽标
- 底部「查看日志 →」跳 /journal

### 2.8 Career Status（底部全宽条）
- 左：当前进行中的投递方向名 + 状态点
- 中：4 个统计卡（投递总数 / 面试中 / 待面试 / 已拿 offer），数字大字 + 标签
- 右：「求职 →」跳 /career

## 3. 移动端（<768px）降级

- 顶栏导航收进底部 Tab 栏（5 个主模块 + 更多）
- Hero 进度环缩小并上移；Continue Learning 保持横向滑动
- Today's Tasks 与 Recent Activity 变为上下堆叠
- Featured Projects 单列
- Career Status 4 卡变为 2×2

## 4. 状态与空态设计

| 状态 | 表现 |
|---|---|
| 加载中 | 各分区独立 Skeleton 卡片（App Store 风格灰块） |
| 数据为空 | 分区级空态卡片 + 引导 CTA（如"添加第一个任务"） |
| 今日任务全完成 | Today's Tasks 显示祝贺空态 🎉 |
| 未登录 | 整页替换为登录页（不进入本布局） |

## 5. 数据依赖（对应 api.md）

| 分区 | API 字段 |
|---|---|
| Hero | `hero` |
| Continue Learning | `continue_learning` |
| Learning Progress | `learning_progress` |
| Featured Projects | `featured_projects` |
| Today's Tasks | `today_tasks` |
| Recent Activity | `recent_activity` |
| Career Status | `career_status` |

> 一次 `GET /api/dashboard` 拉取全部，Svelte 5 `$state` 缓存，切页返回不重复请求。
